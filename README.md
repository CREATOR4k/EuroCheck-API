# EuroCheck-API

Веб-API для парсинга, валидации и хранения данныхEuroCheck. Проект разработан на языке Python с использованием современных библиотек для создания быстрых и надежных веб-служб.

## 🚀 Описание архитектуры

Проект имеет четкую модульную структуру:
* **app/main.py** — Точка входа в приложение, инициализация FastAPI.
* **app/router.py** — Определение маршрутов (endpoints) API и маршрутизация запросов.
* **app/schemas.py** — Схемы валидации данных (Pydantic модели) для входящих и исходящих запросов.
* **app/parser.py** — Логика синтаксического анализа (парсинга) поступающих документов или данных.
* **app/storage.py** — Слой работы с хранилищем данных (база данных или файловое хранилище).

## 🛠 Технологический стек

* **Python 3.13** (актуальная версия среды выполнения)
* **FastAPI** (высокопроизводительный веб-фреймворк для создания API)
* **Pydantic** (валидация данных и управление настройками)
* **Uvicorn** (ASGI-сервер для запуска приложения)

## 📦 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd EuroCheck-API
```

### 2. Настройка виртуального окружения
```bash
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
# или
venv\Scripts\activate     # Для Windows
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```
*(Примечание: Убедитесь, что вы зафиксировали зависимости в файле requirements.txt)*

### 4. Запуск сервера разработки
```bash
uvicorn app.main:app --reload
```

После запуска интерфейс API и интерактивная документация будут доступны по адресам:
* **Swagger UI:** [http://127.0.0](http://127.0.0)
* **ReDoc:** [http://127.0.0](http://127.0.0)

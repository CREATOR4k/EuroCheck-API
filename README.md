# EuroCheck-API

Веб-ориентированный сервис (API) для автоматического парсинга, анализа и каталогизации данных из чеков торговой сети **«Евроопт»**. Проект помогает автоматизировать учет расходов, извлекая из чеков структуру купленных товаров, цены, примененные скидки по карте «Е-плюс» и итоговые суммы.

## ✨ Основной функционал

* **Парсинг чеков:** Извлечение структурированной информации (наименование товара, количество, цена за единицу, итоговая стоимость позиции) из сырого текста чека.
* **Валидация данных:** Строгая проверка типов данных и сумм с помощью Pydantic-схем (проверка корректности расчетов, даты и реквизитов чека).
* **Хранение истории:** Сохранение распарсенных чеков в базу данных для последующего анализа расходов.
* **Интерактивная документация:** Автоматическая генерация Swagger-документации для быстрой интеграции с мобильными или веб-клиентами.

## 📂 Архитектура проекта

Приложение построено по модульному принципу:
* `app/main.py` — Точка входа, инициализация и базовая настройка FastAPI-приложения.
* `app/router.py` — Эндпоинты API (обработка HTTP-запросов на загрузку, парсинг и получение чеков).
* `app/schemas.py` — Pydantic-модели, описывающие структуру чека «Евроопт» (Товар, Чек, Ответ API).
* `app/parser.py` — Ядро сервиса; содержит алгоритмы регулярных выражений или правил для разбора текстового содержимого чека.
* `app/storage.py` — Модуль для записи сохраненных чеков в базу данных или файловое хранилище.

## 🛠 Технологический стек

* **Python 3.13**
* **FastAPI** — для создания быстрого и легковесного асинхронного API.
* **Pydantic** — для валидации структуры данных чека.
* **Uvicorn** — ASGI-сервер для локального запуска и развертывания.

## 🚀 Быстрый запуск

### 1. Подготовка окружения
Клонируйте репозиторий и настройте виртуальное окружение:
```bash
git clone https://github.com
cd EuroCheck-API
python -m venv venv

# Активация окружения:
# Для Linux/macOS:
source venv/bin/activate
# Для Windows:
venv\Scripts\activate
```

### 2. Установка зависимостей
```bash
pip install fastapi uvicorn pydantic
```
*(Или `pip install -r requirements.txt`, если файл уже создан)*

### 3. Запуск сервера
```bash
uvicorn app.main:app --reload
```

После запуска перейдите в браузере по адресу **[http://127.0.0](http://127.0.0)** для доступа к интерактивному интерфейсу Swagger UI, где можно протестировать отправку чеков.

# EuroCheck-API

**EuroCheck-API** — это программный интерфейс (API) для проверки и валидации данных, связанных с европейскими стандартами (например, проверка серийных номеров банкнот евро, валидация IBAN или проверка контрагентов).

## 🚀 Особенности

* **Быстрая валидация**: Мгновенная проверка корректности переданных данных по официальным алгоритмам.
* **Простота интеграции**: Легко встраивается в любые существующие сервисы и приложения.
* **RESTful Архитектура**: Чистый и понятный дизайн эндпоинтов с ответами в формате JSON.

## 🛠 Технологический стек

* **Язык программирования:** Python 3.10+
* **Фреймворк:** FastAPI / Flask (каталог `app`)
* **Лицензия:** MIT Лицензия

## 📋 Требования

Для запуска проекта вам понадобятся:
* Python 3.10 или выше
* Менеджер пакетов `pip`

## 🔧 Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd EuroCheck-API
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv venv
   # Для Linux/macOS:
   source venv/bin/activate
   # Для Windows:
   venv\Scripts\activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```
   *(Примечание: если файл `requirements.txt` отсутствует, установите необходимые библиотеки из папки `app` вручную)*

4. **Запустите сервер разработки:**
   ```bash
   python app/main.py
   ```

## 📐 Использование API

### Пример запроса

**`GET /api/v1/check`**

Параметры запроса (Query Params):
* `value` (string) — значение для проверки (например, серийный номер).

### Пример ответа

```json
{
  "status": "success",
  "valid": true,
  "details": {
    "type": "Euro Banknote",
    "country_of_issue": "Germany",
    "checksum_verified": true
  }
}
```
